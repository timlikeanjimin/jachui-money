1. 개인정보를 수집하지 않습니다

자취머니는 회원가입·로그인이 없는 서비스입니다. 이용자가 입력하는 생활비·월급 등의 금액은 이용자의 브라우저 안에서만 계산되며, 서버로 전송되거나 저장되지 않습니다. 페이지를 닫으면 입력값은 사라집니다.

2. 호스팅 관련 안내

본 사이트는 GitHub Pages에서 호스팅됩니다. 호스팅 제공자(GitHub)는 보안 목적으로 방문자 IP 주소 등 표준 접속 기록을 자체 정책에 따라 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보 보호정책을 참고하세요.

3. 쿠키 · 광고 · 분석 도구

자취머니는 서비스 개선과 방문자 통계를 위해 Google Analytics 4를 사용합니다(2026년 6월 12일부터). 이 도구는 쿠키를 통해 익명화된 방문 정보(방문한 페이지, 유입 경로, 기기 유형 등)를 수집합니다. 이용자가 입력하는 금액은 여전히 수집·전송되지 않습니다. Google의 데이터 처리 방식은 Google 개인정보처리방침을 참고하세요.

광고는 현재 사용하지 않습니다. 추후 광고(Google AdSense, Kakao AdFit 등)를 도입하는 경우 본 방침에 먼저 반영하여 고지합니다.

4. 콘텐츠의 성격

자취머니가 제공하는 평균 비교·절약 팁은 공개 통계(통계청 가계동향조사 등)를 바탕으로 한 참고용 정보이며, 재무·투자 자문이 아닙니다.

5. 문의

본 방침이나 서비스에 대한 문의는 GitHub 이슈 페이지로 남겨주세요.
